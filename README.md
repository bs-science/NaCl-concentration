# NaCl 농도 추산기

Tris–mCP 용액의 **흡광도비**를 이용하여 **첨가한 NaCl의 몰농도(M)**를 추산하는 Python 데스크톱 프로그램입니다. 기본 검량선은 **2026-11-05의 3차 실험**만 사용하며, **730.1 nm의 일정한 바탕선 오프셋을 제거하는 보정**을 기본 적용합니다. 추가 검량자료를 불러오거나, 별도 시료로 **목표 절대오차 ±0.30 M**를 검증할 수 있습니다.

**현재 확보한 자료로는 미지 시료에서 ±0.30 M를 달성했다고 확인할 수 없습니다.** pH·온도와 지시약 없는 배경 용액을 측정하지 않아, 이들에 대한 보정은 수행하지 않습니다. 바탕선 보정은 장파장 흡광도가 파장에 무관한 오프셋이라는 가정에 한정됩니다. 아래 내부 보간 오차는 같은 실험의 기준점을 일부 제외하여 계산한 값입니다.

## 실행

설치부터 CSV 입력·결과 저장, GUI가 뜨지 않을 때의 오류 확인 절차는 [이용 방법 및 GUI 문제 해결](사용방법_문제해결.md)을 참고하세요.

Tkinter가 포함된 Python 3.10 이상에서 동작합니다. 해당 폴더에서 의존성을 설치한 뒤 실행하세요.

```powershell
python -m pip install -r requirements.txt
python .\app.py
```

- **CSV 열기**에서 시료 하나의 Vernier CSV를 선택하면 434.2, 578.3, 730.1 nm의 흡광도를 읽습니다. 세 값을 직접 입력할 수도 있습니다.
- **730.1 nm 바탕선 보정 적용**을 해제하면 기존의 두 파장 흡광도비를 사용합니다. 입력값에는 보정 전 측정값을 넣으세요.
- **기준점 예시**는 현재 검량자료의 중간 농도에서 실제로 측정한 흡광도를 불러옵니다. 기본 자료에서는 1.00 M입니다.
- R이 기준 범위를 벗어나면 **기준 범위 밖**을 표시합니다.
- 작은 창에서는 세로 스크롤로 검증 표와 설명까지 확인할 수 있습니다.
- **현재 추산값 저장**은 보정 전 입력값, 보정 모드, 계산에 사용한 흡광도비, 추산 농도, 검량자료 출처 및 검증 상태를 CSV에 기록합니다.
- **참고 문헌**에서 사용 논문과 적용 범위를 확인할 수 있습니다.

시료의 스펙트럼 CSV는 쉼표 구분, UTF-8 또는 CP949 인코딩을 지원합니다. 파장(nm)과 흡광도 열이 인접한 단일 스펙트럼을 사용합니다. 보정 모드에서는 434.2, 578.3, 730.1 nm가 모두 있어야 하며, 파장 표기의 수치 오차를 위해 0.001 nm의 허용 범위를 둡니다. 빈 추가 데이터 열은 무시합니다. 730.1 nm가 없는 CSV는 보정 모드에서 오류를 표시하며, 이 값을 0으로 대체하지 않습니다.

## 추가 검량자료와 별도 검증자료

**CSV 양식 저장**으로 빈 양식을 만든 후, 알려진 농도와 보정 전 측정 흡광도를 한 행에 하나씩 입력합니다. 검량·검증 자료는 UTF-8 CSV로 저장합니다.

| 열 이름 | 내용 |
|---|---|
| `concentration_M` | 실제 조제한 NaCl 농도(M) |
| `A434_2` | 반올림 전 434.2 nm 흡광도 |
| `A578_3` | 반올림 전 578.3 nm 흡광도 |
| `A730_1` | 반올림 전 730.1 nm 흡광도. 보정 모드에서 필수이며 음수도 허용 |

**검량자료 열기**는 현재 검량선을 선택한 자료로 교체합니다. 서로 다른 농도가 세 개 이상 필요하며, 같은 농도의 반복 측정은 **각 행에 보정을 적용하고 흡광도비를 계산한 뒤 평균**합니다. 보정을 해제한 경우 원래 비율을 평균합니다. 농도별 평균 비율이 엄격하게 증가해야 역산할 수 있습니다. 증가하지 않는 자료는 오류를 표시하고 기존 검량선을 유지합니다. 검량자료는 조제·측정 조건이 일치하는 시료로 구성해야 하며, 다른 실험 회차를 자동으로 합치지 않습니다. **3차 기준으로 복원**으로 기본 자료를 다시 사용할 수 있습니다.

**검증자료 열기**에는 검량선 작성에 사용하지 않은 별도 시료를 넣습니다. 조제 농도, 추산 농도, 부호 있는 오차, ±0.30 M 충족 여부를 표시합니다. 오차는 `추산 농도 − 조제 농도`이고 목표 판정은 그 절댓값으로 합니다. 0 M 시료도 같은 절대오차 기준을 적용합니다.

- 범위 밖 시료는 외삽하지 않고 전체 개수와 표에 포함합니다.
- 농도·흡광도비가 검량자료나 앞선 검증 행과 같은 값은 **독립성 확인 필요**로 표시하고 오차 통계에서 제외합니다. 이 표시는 수치상 일치에 대한 점검이며, 실제로 같은 시료인지 자동으로 판별한 것은 아닙니다.
- MAE·RMSE·최대절대오차는 계산 가능한 시료 수와 함께 표시합니다. 목표 판정은 제공된 검증 시료에 한정됩니다.
- 검량선이나 보정 모드가 바뀌면 기존 검증 결과를 비우므로 해당 설정에 맞춰 다시 검증해야 합니다.
- **검증 결과 저장**은 계산하지 못한 행과 사유까지 CSV로 저장합니다.

## 계산

기준 농도는 0.00, 0.40, 0.60, 0.80, 1.00, 1.20, 1.40, 1.60 M입니다. 기본 보정 모드의 R 범위는 약 **0.81942~1.21604**, 보정 해제 시 약 **0.81019~1.23967**입니다. 농도에 따른 R의 증가 방향을 유지하는 PCHIP 곡선을 만들고, 입력한 R과 일치하는 농도를 측정 범위 안에서 역산합니다. 그래프와 내부 검증에도 동일한 곡선을 사용합니다.

```text
보정 적용: R = (A578.3 − A730.1) / (A434.2 − A730.1)
보정 해제: R = A578.3 / A434.2
R = PCHIP(C)
PCHIP(C) − 입력한 R = 0 을 만족하는 농도 C 계산
```

보정 모드에서는 세 파장의 흡광도 모두에 같은 양의 배수를 곱해도 비율과 추산 결과가 같습니다. 파일 이름과 폴더 이름은 계산에 사용하지 않습니다. 3차의 0.00 M CSV는 0.00 M로 계산됩니다. 기준점 자체에서 얻은 일치는 내부 보간 검증의 오차 계산에서 제외합니다.

기준 파일 `reference.csv`에는 실험 원자료 중 `20261105` 폴더의 농도별 세 파장 흡광도를 수록했습니다. 기존 두 파장 값을 보존하고 원본 CSV에서 읽은 `A730_1` 열을 추가했습니다. 원본 스펙트럼 파일은 수정하지 않았습니다.

## 오차 검증

3차의 내부 농도점 여섯 개를 **하나씩 제외**하고, 남은 일곱 점으로 PCHIP 곡선을 새로 만들어 제외한 농도를 추산했습니다. 양 끝 0.00 M와 1.60 M는 제외하면 외삽이 필요하므로 검증 대상에서 제외했습니다.

| 실제 조제 농도 (M) | 바탕선 보정 후 추산값 (M) | 보정 후 오차 (M) | 보정 전 오차 (M) |
|---:|---:|---:|---:|
| 0.40 | 0.42669 | +0.02669 | +0.06796 |
| 0.60 | 0.59452 | −0.00548 | −0.03956 |
| 0.80 | 0.75599 | −0.04401 | −0.03549 |
| 1.00 | 0.99328 | −0.00672 | −0.00784 |
| 1.20 | 1.16174 | −0.03826 | −0.03773 |
| 1.40 | 1.46924 | +0.06924 | +0.06439 |

| 내부 검증 지표 | 보정 전 | 730.1 nm 보정 후 |
|---|---:|---:|
| 평균절대오차(MAE) | 0.04216 M | 0.03173 M |
| RMSE | 0.04668 M | 0.03869 M |
| 최대절대오차 | 0.06796 M | 0.06924 M |
| 절대오차 0.30 M 이하 | 6/6 | 6/6 |

평균절대오차는 약 25% 감소했지만, 최대절대오차는 소폭 증가했습니다. 보정 전후 모두 내부 여섯 사례는 목표 이내이며, 보정이 모든 농도에서 오차를 줄인 것은 아닙니다.

사용자가 지적한 `20261102/0.00M.csv`는 기존 약 **0.59154 M**에서 보정 후 약 **0.56424 M**로 계산됩니다. 이 입력의 절대오차는 여전히 **0.30 M를 초과**합니다. 해당 시료는 검량선 학습에 사용하지 않았으며 결과를 목표값에 맞춰 제한하거나 이동하지 않습니다.

이 수치는 한 회차 내부의 보간 성능을 나타냅니다. 미지 시료에 대한 정확도는 별도 시료 검증이 필요합니다. 특히 기본 실험에서는 NaCl 농도와 함께 mCP와 Tris의 최종 농도도 변했고 pH·온도를 측정하지 않았으므로, 같은 조제·측정 조건에서 참고값으로 사용해야 합니다. 프로그램은 개별 추산값의 ±오차나 95% 신뢰구간을 계산하지 않습니다.

## 문헌의 사용 범위

[무료 공개 문헌과 서지 정보](REFERENCES.md)에 본문 링크, 검토 부분, 적용 판단을 기록했습니다. 최종 보고서에 이미 수록한 논문과 앞서 제시한 논문을 제외하고, Lai 등(2016, 2017년 정정문 포함), Li 등(2020), Rivaro 등(2021)의 공개 원문을 검토했습니다. Rivaro 등(2021)의 730 nm 바탕선 보정을 참고하여 가장 가까운 실제 측정점인 730.1 nm를 사용합니다. 지시약 없는 배경 용액의 측정이 없으므로 해당 논문의 전체 보정 절차를 재현한 것은 아닙니다. 미측정 pH·온도나 지시약의 화학적 영향은 보정하지 않으며 외부 논문 수치를 검량점에 합산하지 않았습니다. PCHIP 구현에 관한 무료 SciPy 공식 문서는 별도로 안내했습니다.
