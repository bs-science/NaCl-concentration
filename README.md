# NaCl 농도 추산기

Tris–mCP 용액의 **흡광도비 R = A(578.3 nm) / A(434.2 nm)**를 이용하여 **첨가한 NaCl의 몰농도(M)** 후보를 구하는 한국어 Python 데스크톱 프로그램입니다. 각 회차의 여덟 시료로 만든 세 기준 곡선을 비교합니다. 실제 미지 시료에 대한 정확도는 아직 검증되지 않았습니다.

## 실행

Tkinter가 포함된 Python 3.10 이상에서 동작합니다. 사용하는 Python에 Tkinter가 있는지는 `python -m tkinter`로 확인할 수 있습니다. 저장소를 내려받아 압축을 풀거나 복제한 뒤, 해당 폴더에서 실행합니다.

```powershell
python .\app.py
```

1. 두 파장의 흡광도를 입력하거나, 시료 하나의 Vernier CSV를 선택합니다. 내장된 3차 예시로도 사용해 볼 수 있습니다.
2. 회차를 모르면 세 회차의 후보를 함께 확인하세요. 조제·측정 조건이 어느 회차와 같은지 알고 있다면 그 회차를 선택하세요. CSV 이름과 폴더 이름으로 회차나 농도를 정하지 않습니다.
3. 곡선이 같은 R을 여러 번 지나면 해당 농도 후보를 모두 표시합니다. R이 선택한 회차의 측정 범위를 벗어나면 그 회차에서는 외삽하지 않습니다.

CSV는 쉼표 구분, UTF-8 또는 CP949 인코딩을 지원합니다. 파장(nm)과 흡광도 열이 인접한 단일 스펙트럼을 사용합니다. 434.2와 578.3 nm가 모두 있어야 하며, 파장 표기의 수치 오차를 위해 0.001 nm의 허용 범위를 둡니다. 빈 추가 데이터 열은 무시합니다. 여러 시료의 값이 함께 들어 있는 파일은 한 시료씩 분리하여 사용하세요.

## 계산과 적용 범위

- 각 회차에서 농도 순으로 인접한 측정점을 직선으로 잇고, 입력한 R과 교차하는 모든 농도를 구합니다. 두 흡광도에 같은 양의 배수를 곱해도 비율과 결과는 같습니다. 기준 농도는 0.00, 0.40, 0.60, 0.80, 1.00, 1.20, 1.40, 1.60 M이며, 계산에는 반올림 전 값을 사용합니다.
- 예를 들어 1차 0.00 M CSV의 흡광도비는 약 0.8637015입니다. 이 비율은 1차 기준에서 **0.00 M**, 2차 기준에서 **약 0.05, 0.60, 0.62 M**, 3차 기준에서 **약 0.89 M**에 대응합니다. 1차 기준에서 원래 농도가 나오는 것은 측정한 기준점을 다시 입력한 결과입니다.
- 실험에서 NaCl 원액을 늘릴 때 Tris와 mCP의 최종 농도도 함께 낮아졌고, 각 시료의 pH는 측정하지 않았습니다. 같은 R을 가진 다른 조성의 용액에 대해 실제 NaCl 농도를 특정하기 어렵습니다.

### 3차 곡선의 검증 결과

여덟 농도에서 R이 매번 증가한 3차 곡선에 아래 자료를 적용했습니다. 표의 오차는 이 곡선에서 얻은 단일 추산값에 대해 계산했습니다.

| 검증 자료 | 추산 가능 / 비교 대상 | 평균절대오차 |
|---|---:|---:|
| 3차의 내부 농도를 하나씩 제외 | 6 / 6 | 0.060 M |
| 3차 기준을 1차에 적용 | 8 / 8 | 0.425 M |
| 3차 기준을 2차에 적용 | 4 / 8 | 0.501 M |

평균절대오차는 추산 농도와 실제 조제 농도의 차이에 절댓값을 취해 평균한 값입니다. 3차 내부 비교에서는 양 끝점을 제외했습니다. 2차의 1.00~1.60 M 시료 네 개는 기준 범위를 벗어나 평균에서 제외했습니다. 이 값은 개별 추산 농도의 오차 한계를 보장하지 않습니다.

기준 파일 `reference.csv`에는 [실험 원자료](https://github.com/bs-science/data)의 세 회차(2026-10-29, 2026-11-02, 2026-11-05)와 농도별 두 파장의 흡광도 24쌍을 수록했습니다.
