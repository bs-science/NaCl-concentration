# NaCl 농도 추산기

Tris–mCP 용액의 **흡광도비 R = A(578.3 nm) / A(434.2 nm)**를 이용하여 **첨가한 NaCl의 몰농도(M)**를 추산하는 Python 데스크톱 프로그램입니다. 기준 자료, 그래프, 오차 검증은 모두 **2026-11-05의 3차 실험**을 사용합니다.

## 실행

Tkinter가 포함된 Python 3.10 이상에서 동작합니다. 해당 폴더에서 실행하세요.

```powershell
python .\app.py
```

- 434.2 nm와 578.3 nm 흡광도를 입력하거나 **CSV 열기**에서 시료 하나의 Vernier CSV를 선택합니다.
- **3차 예시**는 조제 농도 1.00 M인 기준점의 측정값을 불러옵니다.
- R이 기준 범위를 벗어나면 **기준 범위 밖**을 표시합니다.
- 작은 창에서는 세로 스크롤로 검증 표와 설명까지 확인할 수 있습니다.

CSV는 쉼표 구분, UTF-8 또는 CP949 인코딩을 지원합니다. 파장(nm)과 흡광도 열이 인접한 단일 스펙트럼을 사용합니다. 434.2와 578.3 nm가 모두 있어야 하며, 파장 표기의 수치 오차를 위해 0.001 nm의 허용 범위를 둡니다. 빈 추가 데이터 열은 무시합니다.

## 계산

기준 농도는 0.00, 0.40, 0.60, 0.80, 1.00, 1.20, 1.40, 1.60 M이고 R의 범위는 약 0.81019~1.23967입니다. 반올림 전의 R을 인접한 두 기준점 사이에서 선형 역보간합니다.

```text
R = A578.3 / A434.2
C = C0 + (R − R0) / (R1 − R0) × (C1 − C0)
```

두 흡광도에 같은 양의 배수를 곱해도 비율과 추산 결과는 같습니다. 파일 이름과 폴더 이름은 계산에 사용하지 않습니다. 3차의 0.00 M CSV는 0.00 M로 계산됩니다. 기준점 자체에서 얻은 일치는 내부 보간 검증의 오차 계산에서 제외합니다.

기준 파일 `reference.csv`에는 [실험 원자료](https://github.com/bs-science/data)의 농도별 두 파장 흡광도 8쌍을 수록했습니다.

## 오차 검증

3차의 내부 농도점 여섯 개를 **하나씩 제외**하고, 남은 일곱 점으로 제외한 농도를 추산했습니다. 양 끝 0.00 M와 1.60 M는 제외하면 외삽이 필요하므로 검증 대상에서 제외했습니다.

| 실제 조제 농도 (M) | 해당 점을 제외한 추산값 (M) | 추산값 − 조제값 (M) |
|---:|---:|---:|
| 0.40 | 0.41153 | +0.01153 |
| 0.60 | 0.52142 | −0.07858 |
| 0.80 | 0.70418 | −0.09582 |
| 1.00 | 0.93400 | −0.06600 |
| 1.20 | 1.13578 | −0.06422 |
| 1.40 | 1.44173 | +0.04173 |

- 평균절대오차(MAE)는 여섯 절대오차의 평균인 **0.05965 M**입니다.
- 제곱평균제곱근오차(RMSE)는 여섯 오차 제곱의 평균에 제곱근을 취한 **0.06546 M**입니다.
- 최대절대오차는 위 여섯 사례에서 가장 컸던 **0.09582 M**입니다.

이 수치는 한 회차 내부의 보간 성능을 나타냅니다. 미지 시료에 대한 정확도, 개별 추산값의 ±오차, 95% 신뢰구간은 별도 반복측정과 독립 시료 검증이 필요합니다. 특히 실제 시료에서는 NaCl 농도와 함께 mCP와 Tris의 최종 농도도 변했고 pH를 측정하지 않았으므로, 같은 조제·측정 조건에서 참고값으로 사용해야 합니다.

```powershell
python -m unittest -v
```
